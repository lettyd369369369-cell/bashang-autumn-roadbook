CORE · D4—D7 · 天气调度

核心四天：住进秋天里

未来 48 小时动态调整

进入乌兰布统后，每天晚上看未来两天天气（降雨 / 雨夹雪 / 风力 / 能见度 / 最低温 / 道路结冰），把下面三个模块重新排序：

🌤 天气策略

本次行程真实预报（09/26 更新，Open-Meteo）：D2 赶路日沿途有雨；坝上核心期 -3~15℃、多大风；克旗穿越执行前重点看能见度与结冰。进入乌兰布统后每晚看未来 48 小时，三个模块（乌兰布统核心 / 温泉转场 / 克旗穿越）按天气互换。雨天看森林、晴天看草原公路；大风天减少长时间户外。

⛽ 加油

进坝前加满；坝上和草原乡镇加油站少、营业时间不定，见站就加。出发前查备胎和胎压。

🧥 穿衣

按本次预报备衣：坝上核心期 D4–D8 白天最高 3~16℃、夜间最低 -3℃，D6 大风体感更低——羽绒服 + 抓绒 + 防风壳直接全套，帽子手套围巾都带上；赶路段和平原段白天 20℃+，洋葱式穿脱。

🛣 路况安全

区间测速多，别超速；草原土路雨天勿硬闯（蛤蟆坝—小河头尤其）；9/15–11/15 正蓝旗一带防火戒严，只走开放公路与正规景区；非赶路日每天车程控制在 5h 内，两人轮换驾驶。
