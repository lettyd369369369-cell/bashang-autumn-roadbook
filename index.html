CORE · D5—D9

塞罕坝的林海、乌兰布统的草原、克旗三条景观线——这段是主菜；从 D9 起不写死路线，按天气现场选。

D5 · 09/29

塞罕坝｜秋色从路边开始

承德 → 御道口 → 塞罕坝 · ≈250km · 4.5h

走承围高速一路爬升进林区，秋色从车窗外开始变色。不急着直冲林场——第一个宝藏点就藏在半路上。
天气
☁️ 阴 · 1~10℃ · 风4级（阵风更大）

天气穿衣
白天 14℃ / 夜里 3℃；海拔一上来就是另一个季节——羽绒服正式上身，帽子手套备好。
宝藏支线

怎么玩
下午逛机械林场周边白桦 + 落叶松；傍晚七星湖湿地日落，顺路泰丰湖。

进坝规则：最后一个大加油站务必加满；早晚 5℃ 左右，羽绒服上身。
轻松度 ★★★★☆重点：森林日落

D7 · 10/01

乌兰布统｜完全按天气走的一天

全天机动 · ≤50km · 晴/阴两套方案

不赶景点、不全刷。两条线二选一：天气好优先走北沟侧，路况一般就退回经典线。
天气
☁️ 阴 · -2~8℃ · 风5级
预报偏阴，大概率走阴天版；草原空旷，防风保暖做到位
天气穿衣
白天 12℃ / 夜里 0℃ 上下；赶日出必须全副武装：羽绒服 + 帽子手套 + 暖宝宝。
A 线 · 首选尝试
北沟 → 蛤蟆坝 → 小河头：白桦、牧群、村落和沟谷，地形更丰富、更避人流。
注意：蛤蟆坝—小河头一带有非铺装土路，雨后不硬走。
B 线 · 稳妥兜底
公主湖晨雾 → 五彩山 → 野鸭湖 → 将军泡子日落：道路条件好；国庆人多，公主湖 7 点前到。

涮羊肉
住哪里

二选一规则：不要 A、B 全刷——看天定一条，把留白留给草原本身。

D9 · 10/03

克旗自由日｜三套方案，早上看天再定

热阿 / 达达 / 黄岗梁候选池 · 热阿+达达全程约 210km · 不提前订住宿

全天不锁死。昨晚看预报、早上看天，再决定今天开哪条——把克旗最好的路留出选择权。
天气
🌨 小阵雪 · -2~2℃ · 风4级
热阿线或遇今秋初雪：景是加分项，山路湿滑务必慢行、弯道停车进观景位
天气穿衣
白天 10℃ / 夜里 -2℃ 左右；黄岗梁高处更冷、风硬，羽绒 + 防风壳必穿，暖宝宝多带两片。
A · 天气特别好
热水塘 → 黄岗梁 → 热阿线 → 阿斯哈图西门（顺停音乐公路）→ 达达线 → 白音敖包沙地云杉 / 贡格尔 → 达里湖，全程约 210km，晚上就近住达来诺日，不赶多伦。
B · 天气一般
只跑黄岗梁 + 热阿线：重点停2029 驿站（崖壁观景台 / 观星平台 / 咖啡工坊 / 共享书屋，今年新开）和白桦林；下午早撤，晚上回热水塘或经棚。
C · 大风低云雨
不硬上黄岗梁：热水塘休息 → 经棚吃饭 → 提前往多伦方向移动，把第二天过松——这是最舒服的版本。
吃什么
经棚午餐；晚上达里湖华子鱼别错过
华子鱼手把肉
住哪里
按方案现场定：达来诺日 / 热水塘 / 经棚——今晚不提前订死。
现实提醒：10/3 前后各家预报已现分歧，克旗夜间已近 0℃；油箱见站就加，弯道停车进观景位，不占路肩。
轻松度 ★★★★☆重点：把选择权留给天气

⛽ 加油

进坝前加满；坝上和草原乡镇加油站少、营业时间不定，见站就加。出发前查备胎和胎压。

🧥 穿衣

按本次预报备衣：坝上核心期 D5–D9 白天仅 1~10℃、夜间最低 -3℃，D6 大风体感更低——羽绒服 + 抓绒 + 防风壳直接全套，帽子手套围巾都带上；去程/回程平原段白天 20℃+，洋葱式穿脱。

🛣 路况安全
