# 坝上秋色 13 天自驾路书 · V3.1 弹性锚点版

解压后直接上传 GitHub Pages，或整个文件夹发微信，对方解压双击 `index.html` 即可。

- `index.html` — 路书主页（总览+示意地图 / 13天图文卡片 / 美食 / 贴士 / 行前清单）
- `assets/images/` — 15 张配图：`hero.jpg`（封面）+ `d1.jpg`…`d13.jpg`（每天一张）+ `food.jpg`（美食）
- `assets/css/style.css` — 样式（移动端优先，电脑打开自动居中）
- `assets/js/main.js` — 交互（清单勾选记忆、导航高亮）

无外部依赖，离线可用。配图为真实照片（CC 授权 / 公有领域），来源明细见 `assets/images/credits.json`。
路线为「固定锚点 + 弹性支线」：D7 / D9 / D10 均含按天气二选一或三选一的现场方案，克旗段住宿不提前订死。
